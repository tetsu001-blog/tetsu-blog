こんにちは、てつです！

先月（2026年10月）、興味本位で中国発のフルモーダルAI **「MiniMax」のサブスク（M Plan の Go：$22/月）** に課金して、ファーストインプレッションの記事を書きました。

詳しくはこちらの記事で書いてます

https://tetsu-blog.net/posts/minimax-m3-comparison/

前回の記事の最後に、私はこう書きました。

> **「興味本位で、1ヶ月使用してみようと思い課金したので、また戻ると思いますが今のところ不満はありません。あえて、不満を上げるなら『回答に中国語が稀に混ざる。』ぐらいです。1ヶ月使用してみて、問題があればまた記事にします。」**

あれからちょうど **1ヶ月** が経ちました。

この1ヶ月間、自分のPC環境で MiniMax Code を実際に使い倒してみてどうだったのか？
そのまま継続したのか、それとも予定通り解約したのか？

先に**1ヶ月使ってみた結論**からお伝えします。

- **最終判断**：予定通り **1ヶ月で解約** し、現在は **Antigravity / Gemini** に一本化した
- **良かった点①（作業）**：**既存コードや設定ファイルのリファクタリング・PC内のファイル整理・自動化スクリプト作成** ではエラーもなく超優秀
- **良かった点②（生成）**：**画像生成・動画生成のクオリティは文句なしの出来栄え**（ただし音声付き動画はクレジット不足で作れず）
- **利用枠と実質作業量のリアル**：通常枠＋デイリーボーナスで**他社AIより利用できる量は多い**が、日本語が含まれると多言語混入の修正でラリー回数が増えるため、**完了できる作業量としてはトントン**
- **向いている人**：コード作成など **「日本語を含まない作業」にたくさん利用したい人**
- **解約の決め手**：複数AIのサブスクを二重課金するのを避け、日本語もコードもシームレスなメイン環境（Antigravity / Gemini）に絞るため

今回は、カタログスペックやベンチマークだけでは分からなかった **「1ヶ月使い続けて見えた MiniMax Code のリアルな実力と弱点」** を正直にまとめます。

---

## 1. この1ヶ月間、MiniMax Codeを何に使ったのか？

契約していたのは、月額 $22（約3,300円）の **「M Plan（Go）」** です。

最初のうちはブログ記事の下書きなどにも試していたのですが、1ヶ月を通して一番活躍したのは **「PC内のファイル整理・自動化スクリプト作成」**、特に **「既存コードや設定ファイルのリファクタリング・整理」** でした。

実際にやらせてみて感じたのは、**「機械的な作業やコードの構造整理における安定感」** です。

- ごちゃごちゃになった既存スクリプトの整理・共通化
- AIツール別の設定ファイルやスキル定義ファイルの整理
- PC内のローカルファイル管理や自動化用のPythonスクリプト作成

こういった **「正解がコードやファイル構造としてハッキリしている作業」** においては、100万トークンの広いコンテキスト（記憶容量）も相まって、複数ファイルを一気に読み込ませても迷子にならず、きっちり仕事を完遂してくれました。

「自分で手を動かすと地味に時間がかかるファイル整理やリファクタリング」を丸投げするエージェントとしては、間違いなく一線級の実力があります。

---

## 2. 制限とクレジットのリアル：他社AIより「使える量」は多い！

前回の記事で、MiniMax M Plan の弱点として **「短期枠が5時間更新（ChatGPT Plusは3時間更新）」「トークンの絶対数が非公開になった」** という点を挙げました。

「朝ガッツリ使ったら、昼まで止まってしまうのでは？」と心配していたのですが……

**1ヶ月使ってみた結果、5時間枠・週次枠ともに余裕があり、制限にはほぼ引っかかりませんでした。**

厳密にトークン数を実測したわけではないのであくまで**体感**にはなりますが、**同じ価格帯の他社AI（Claude Pro や ChatGPT Plus など）と比べても、利用できる量は多い**と感じました。

![](/images/Pasted-image-20261114100653.png)

さらに大きいのが、**「デイリーボーナス分のクレジット」もそのまま使用できる点**です。

![](/images/Pasted-image-20261114100723.png)

MiniMax ではログインボーナスとして毎日クレジット（Credits）が貰える仕組みがあり、通常のサブスク枠に加えてこのボーナス分のクレジットも消費に回せます。

- **そもそもの5時間枠・週次枠のキャパシティが広め（体感）**
- **＋ デイリーボーナスで貰えるクレジットも上乗せして使える**

この2つが合わさるため、単純な「動かせる総量」で見れば他社AIよりも間違いなく多いと思います。
（※ただし、後述する「日本語の修正ラリー問題」があるため、最終的な作業効率にはちょっとした落とし穴もあります）

## 3. 画像・動画生成を試してみた結果：出来栄えは「文句なし」！

MiniMax のもうひとつの強みが、テキストやコードだけでなく **「画像生成・動画生成も同じプラットフォーム内で使えるフルモーダルAI」** だということです。

せっかくの機会なので、MiniMax Code を使って実際に**画像**と**動画**も作成してみました。

まずは画像生成から。実際に生成した画像がこちらです。

わざわざ別の画像生成AIを契約しなくても、コーディング用のサブスク1本でこのレベルの画像が出せるのは素直にすごいと感じました。

### 実際に MiniMax で作成した動画（音声なし）

続いて、MiniMax 自慢の動画生成モデルも試してみました。実際に生成した動画がこちらです！

動画のクオリティ自体も、動きの滑らかさや描写力を含めて **文句なしの出来栄え** でした。

ただ、ここで1つだけリアルな注意点があります。
実はこの動画、**「音声付きの動画」を作ろうとしたのですが、手持ちのクレジットが不足していて作成できず、音声なしの動画になりました。**

- **テキストやコード生成、画像生成**：通常枠＋デイリーボーナスのクレジットで十分余裕で回せる

「動画生成（特に音声付き）をメインでガンガン回したい」という場合は、上位プラン（Explore以上）にするか追加クレジットの購入が必要になりそうです。とはいえ、お試しで映像を作る分には十分すぎる品質でした。

## 4. 最大の壁：「多言語混入」で修正ラリーが増え、実質作業量はトントンに

コード整理でも優秀、利用枠も多い、画像や動画のクオリティも文句なし。
そんな MiniMax Code ですが、1ヶ月使い続けて **「ここだけはやっぱり厳しいな」** と痛感したポイントがあります。

それが **「日本語の回答に、中国語・韓国語・英語が混ざる問題」** です。

前回の記事でも「稀に中国語が混ざる」と触れましたが、1ヶ月間いろいろな場面で使ってみると、**長文だけでなく短文のやり取りでも、所々に多国籍な言語が混ざることがありました。**

上記の動画を作成したときの回答です。水色にマーカーをした部分（「金色レトリー」「lowsidedトラッキング」「回头」「追加到位」）で、中国語や英語が混ざって日本語がおかしくなっています。
![](/images/Pasted-image-20261114101710.png)

具体的にどういうことが起きるかというと、

| 場面 | MiniMax Code の挙動 | 実用上の影響 |
|---|---|---|
| **コード作成・リファクタリング** | コード自体は正確に動く | **問題なし（優秀）** |
| **ファイル整理・コマンド実行** | パス処理やスクリプト実行は的確 | **問題なし（優秀）** |
| **画像・動画生成** | クオリティが非常に高い | **問題なし（文句なしの出来栄え）** |
| **日本語での解説・短文の返答** | 所々に中国語・韓国語・英語が混じる | 読めるが、地味に脳が疲れる |
| **日本語を含む成果物の作成** | 不自然な漢字や多言語が混入する | **修正指示のラリー回数が増える** |

たとえば、前回の記事（あえて MiniMax に書かせてみた記事）を読み返しても、

- 「コストパフォーマンス」が **「成本パフォーマンス」** になる
- 「それどころか」が **「甚至」** になる
- 「公開していない」が **「公开发していない」** になる

といった具合に、日本語の漢字と似ている中国語や、韓国語・英語の単語がしれっと紛れ込みます。

ワークスペースの指示ファイル（`CLAUDE.md` など）に **「文章中に中国語の混入・機械翻訳臭・不要な英単語の混入がないことを必ず確認する」** と明記してみましたが、それでも完全には防げませんでした。

### 結果として「完了できる作業量」は他社AIとトントンになる

ここが1ヶ月使ってみて一番の気づきだったのですが、

1. **クレジットや枠の利用量は、間違いなく他社AIより多い**
2. **しかし、日本語が含まれる作業だと多言語が混ざり、それを直させるために他社AIより修正のラリー回数が増える**
3. **結果として、「最終的に完了できる作業量」で見ると他社AIとトントン（同じくらい）になってしまう**

という現象が起きます。

せっかく使える枠が多くても、「ここの中国語を自然な日本語に直して」というやり取りでターン数とクレジットを消費してしまうため、**日本語が絡むタスクでは枠の多さというメリットが相殺されてしまう**のです。

---

## 5. 結論：MiniMax Codeが「向いている人」と、私が解約した理由

1ヶ月使い倒してみて、**「MiniMax Code がどんな人に向いているか」** がはっきり見えました。

### MiniMax Code が向いている人

> **「コード作成やファイル整理など、日本語を含まない作業にたくさん利用したい人」**

これに尽きます。
PythonやJavaScriptなどのコード作成、既存コードのリファクタリング、設定ファイルの整理といった **「日本語の自然さが成果物に影響しない作業」** であれば、多言語混入による修正ラリーは発生しません。

つまり、**日本語を含まない用途に絞って使うなら、「他社AIより多い利用枠＋デイリーボーナス」の恩恵を100%そのまま受け取れる**ため、めちゃくちゃコスパの良い相棒になります。

### 予定通り「1ヶ月で解約」し、Antigravity / Gemini へ一本化した理由

一方で、私は予定通り **1ヶ月で M Plan（Go）を解約** しました。

![](/images/Pasted-image-20261114101835.png)

解約を決めた一番の理由は、シンプルに **「複数AIのサブスクを二重課金するのを避け、メインのAIに一本化したかったから」** です。

そして現在、私がメイン環境として一本化したのが **「Antigravity / Gemini」** です。

| 比較項目 | MiniMax Code（M Plan Go） | Antigravity / Gemini（現在のメイン） |
|---|---|---|
| **コード作成・ファイル整理** | **◎（優秀・問題なくこなせる）** | ◎（ワークスペース統合が快適） |
| **利用できる量（体感）** | **◎（通常枠＋デイリーボーナスで多い）** | 十分実用的 |
| **日本語絡みの実質作業量** | **△（多言語修正のラリーが増えトントンに）** | **◎（一発で自然な日本語が出るため速い）** |
| **画像・動画生成** | **◎（出来栄え抜群・音声付動画は要クレジット）** | 画像・動画（Veo等）対応 |
| **向いている用途** | **日本語を含まない大量のコード・機械作業** | **記事執筆からコード改修まで全部入り** |

私のように **「日本語でのブログ記事作成も、コード改修も、ファイル整理も全部ひとつのサブスクでやりたい」** という使い方だと、日本語修正のラリーが発生しない **Antigravity / Gemini** に集約する方が、結果的に完了できる作業量でもコスト面でもベストでした。

---

## まとめ：MiniMax Codeを1ヶ月使ってみた最終評価

1ヶ月間、実際に $22 を払って MiniMax Code を使い倒してみた結論をまとめます。

1. **コード作成・リファクタリング・ファイル整理の実力は本物**
   既存コードや設定ファイルの整理、自動化スクリプト作成など、日本語を含まない機械的なタスクでは非常に優秀でした。
2. **利用できる量は他社AIより多いが、日本語が入ると実質作業量はトントン**
   5時間枠＋デイリーボーナスで使える総量は多いものの、日本語が含まれると多言語（中・韓・英）混入の修正でラリー回数が増えるため、完了できる作業量としては他社AIとトントンになります。
3. **画像・動画のクオリティは文句なしの出来栄え**
   生成される画像・動画の品質は非常に高いです（ただし、音声付きの動画はクレジット不足で作成できませんでした）。
4. **使うなら「日本語を含まない作業を大量に回したい人」におすすめ！**
   純粋なコード生成やファイル処理、画像生成などをガッツリ回したい人には間違いなく強い選択肢です。私はサブスクの二重課金を避けて日本語作業も一本化するため、予定通り1ヶ月で解約し **Antigravity / Gemini** に絞りました。
